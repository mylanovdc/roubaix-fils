# Roubaix & Fils — landingspagina

One pager voor **Roubaix & Fils**, een **fictief** niche-parfummerk. Schoolproject 2DGVA, Arteveldehogeschool (Creative Automation), door Mylan Vandecaveye.

- Gebouwd met Claude Code: HTML, CSS en vanilla JS, zonder framework
- Inschrijven via een embedded MailerLite-formulier (double opt-in)
- Lettertypes (DM Serif Display, Space Grotesk) staan lokaal, niet via Google Fonts
- Respecteert `prefers-reduced-motion`

Live: GitHub Pages (branch `main`, map `/`).
